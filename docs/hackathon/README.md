## Как обновить снимок Положения

Страница — React SPA, секции подгружаются по клику. Снимок делается через Playwright: открыть
`?tab=regulations`, кликнуть по каждой кнопке в блоке «Секции» (кнопки дублируются для десктопа и мобильной вёрстки —
брать уникальные по тексту), собрать `innerHTML` панели с `h3.text-base.font-semibold` → `sources/regulations_raw.json`
→ конвертация в Markdown (h3→`##`, подразделы `N.M.`→`###`, p, ul/li, strong, table).

Вкладки «О хакатоне» и «Треки» снимаются как `innerText` элемента `main`. Задания треков без авторизации
не отдаются — API платформы возвращает 401.

При обновлении: текущие снимки переносить в `sources/archive-<дата>/`, чтобы можно было сравнить редакции.
