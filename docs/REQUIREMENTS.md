# Требования кейса → реализация

Состояние после обучения основной модели NOAA GFS, 23.09.2026.
Полный временной протокол: [FORECAST_PROTOCOL.md](FORECAST_PROTOCOL.md).

## Правила исторического прогноза

> «Для каждого прогнозного периода участники должны использовать архивные прогнозы погоды,
> которые были доступны на соответствующий момент времени, а не фактические погодные значения,
> ставшие известными позднее.»

Основной источник — операционные циклы NOAA GFS в публичном S3.
Для каждого выпуска проверяются инициализация и горизонт внутри GRIB,
а S3 `Last-Modified` каждого использованного объекта должен быть `<= as_of`.
730 циклов с 01.03.2024 по 28.02.2026 сохранены в `data/gfs-runs/` вместе
с URL, ETag, диапазонами байтов и контрольными суммами.
Будущие наблюдения, реанализ и измеренный ветер целевого часа в признаки не входят.

Предыдущие модели Open-Meteo Previous Runs сохранены как исследовательские:
их запас +12 ч — допущение, не доказательство исторической публикации.
Основная модель `artifacts/gfs-model/` на это допущение не опирается.

Поиск 400 моделей и выбор ансамбля выполнялись по ноябрю–декабрю 2025.
Январь — мониторинг разработки: он оценивался в нескольких экспериментах,
поэтому его нельзя представлять новым нетронутым тестом. Модель январской
оценки обучена на более ранних целях. Для февраля сохранена отдельная модель,
обученная до 31 января; день отсечки исключён целиком. Инференс проверяет,
что конец обучающей истории не позже `as_of`.

Факта февраля нет: предоставленные CSV заканчиваются 31.01.2026 23:50.
Поэтому февральские значения — прогнозы, метрики фактической ошибки неизвестны.

## Трассировка требований

| Требование | Реализация и свидетельство | Состояние |
|---|---|---|
| Модель почасовой выработки по предоставленной истории | `scripts/train_gfs.py`, `src/gfs_model.py`, `artifacts/gfs-model/model.joblib` | Реализовано; ансамбль 5 MLP, CPU-инференс |
| Самостоятельное получение открытого прогноза по координатам | `scripts/fetch_gfs_runs.py`, координаты `src/data.py`, архив `data/gfs-runs/` | Реализовано; загрузка без ключей, проверка цикла и публикации |
| Почасовой горизонт 24–48 часов | `scripts/predict.py --horizon 24/48`, `src/agent.py` | Реализовано; по 24/48 точек на турбину |
| Получение → подготовка → модель → прогноз → анализ → повторный расчёт при обновлении | `src/agent.py`, очередь `backend/app/`, DuckDB | Реализовано в режиме policy: анализ диапазонов и рампов, хэш входов, новые ревизии при изменениях, переиспользование одинаковых входов |
| Последовательные исторические выпуски с 31 января в течение февраля | `artifacts/gfs-model/february_replay.csv`, `reports/agent-noaa-replay.json` | 29 из 29 API-запусков завершены; 2784 строки, включая мартовский хвост |
| Только прогнозная погода, доступная на момент решения | `src/gfs_weather.py`, ежедневные `.meta.json`, `initialization_time` и `available_at` в API | Проверяется для каждого исходного объекта и выпуска |

В API происхождение каждого часа хранится через `weather.sources` и
`points[].weather_inputs`; для NOAA используется `product=single_run`.
История сохраняется транзакционно для обеих турбин. Замена предыдущей модели
на NOAA создала новую ревизию существующего выпуска, что видно в
`reports/agent-noaa-first-run.json`.

## Что ещё требуется перед сдачей

- **Подтверждение временных настроек:** UTC+5, метка начала интервала,
  выпуск 23:00 по часам CSV пока исследовательские. Нельзя ставить
  `confirmed=true` без ответа организаторов. Другие настройки могут
  потребовать переобучения и повторного replay.
- Пройти браузерный сценарий подключённого frontend: расчёт, история, события
  и CSV. Синтетика отключена; несуществующий факт февраля не рисуется.
- Повторить чистый запуск Docker после подключения NOAA. Предыдущая версия
  проверена Claude, запись сохранена в CHANGELOG; новый API-replay выполнен
  в локальном окружении без GPU для инференса.
- Уточнить формат итоговой выгрузки. Полные выпуски сохраняют 48 часов;
  для целевого февраля есть флаг `in_february`.

## Метрики для отчёта

Январская MAE **0.15947**, RMSE **0.23190**, единица — доля нормализованной
мощности. Персистенция последнего полного часа: MAE 0.34268.
Подробности и ограничения: [отчёт модели](../artifacts/gfs-model/report.md).
Ошибка диагностической кривой по фактическому ветру (`artifacts/power_curve/`)
не является качеством прогноза на 24–48 часов.
