# Прогноз по операционным выпускам NOAA GFS

Основная модель проекта: ансамбль пяти MLP с инференсом на NumPy/CPU.
GPU, PyTorch, сеть и API-ключи для расчёта по сохранённому архиву не нужны.

## Результат

Январь 2026 — месяц мониторинга разработки, не новый независимый тест.
Фактической мощности за февраль у команды нет.

| Модель / горизонт | MAE | RMSE |
|---|---:|---:|
| NOAA GFS, все 1–48 ч | **0.15947** | **0.23190** |
| NOAA GFS, 1–24 ч | 0.15226 | 0.21898 |
| NOAA GFS, 25–48 ч | 0.16692 | 0.24453 |
| Предыдущий ансамбль Previous Runs | 0.16933 | 0.25432 |
| Последний доступный полный час | 0.34268 | 0.45155 |
| Последний доступный такой же час суток | 0.36480 | 0.47933 |

Ошибки измерены в долях нормализованной мощности, не в процентах MAPE.
2928 прогнозных строк, 31 ежедневный выпуск, 1488 уникальных пар
«турбина — целевой час». Среднее смещение новой модели: −0.00368.
Обе персистентные модели используют только телеметрию, известную на `as_of`.
Машинные отчёты: [metrics.json](metrics.json), [baselines.json](baselines.json).

## Обучение

Поиск завершён для 400 конфигураций: 40 на CPU, 180 на RTX 5090 Laptop,
180 на NVIDIA RTX A6000 в Brev. Архитектуры, функции потерь, скорости обучения,
семена и наборы признаков выбирались по ноябрю–декабрю 2025.
Обучение поисковых моделей заканчивается до 31 октября 2025.
Выбрано простое среднее пяти моделей; MAE периода выбора — 0.16261.

Состав: `local-gpu_078`, `local-gpu_101`, `local-gpu_043`,
`cloud-gpu_143`, `cloud-gpu_071`. Протокол и все результаты поиска:
[protocol.json](../gfs-search/protocol.json), [selection.json](../gfs-search/selection.json).

- `validation_model.joblib`: переобучение на данных до 31 декабря 2025,
  используется для январской оценки.
- `model.joblib`: переобучение на данных до 31 января 2026,
  используется для февральских прогнозов. Дни отсечки исключены целиком.
- Перед инференсом проверяется `training_data_available_until <= as_of`.
- Цель — среднее шести исходных измерений. Неполные часы исключаются;
  реальные нулевые мощности сохраняются, пропуски нулями не заполняются.

## Погода и соответствие историческому моменту

Архив содержит 730 ежедневных циклов с 01.03.2024 по 28.02.2026:
[`data/gfs-runs`](../../data/gfs-runs). Источник —
[публичный операционный архив NOAA GFS](https://registry.opendata.aws/noaa-gfs-bdp-pds/).

Для решения в 18:00 UTC выбирается цикл 12:00 UTC с сеткой 0.25°.
Инициализация и горизонт проверяются внутри GRIB. Для каждого исходного объекта
его S3 `Last-Modified` должен быть не позже `as_of`. Сохранены URL, ETag,
диапазоны байтов, SHA-256 полей и извлечённых точек. Дата скачивания архива
сегодня не подменяет историческое время доступности.

Из 17 прогнозных опор одного цикла (6–54 ч, шаг 3 ч) линейно интерполируются
компоненты ветра, температура и давление, затем вычисляется скорость ветра.
Будущая фактическая погода, ERA5 и февральская телеметрия не используются.
Признаки включают плотность воздуха, ρv³, сдвиг ветра по высоте и траекторию
прогнозной погоды, уже доступную в момент решения.

## Получение прогноза

```bash
python -m scripts.predict --as-of 2026-01-31T18:00:00Z --horizon 48
```

`first-forecast.csv` содержит 96 значений первого выпуска.
`february_replay.csv` — 29 выпусков с 31 января по 28 февраля,
2784 строки. Полные горизонты включают начало марта; `in_february`
позволяет выделить только целевой месяц. Запуск через настоящий API-агент
завершил 29 из 29 расчётов, без ошибок:
[`reports/agent-noaa-replay.json`](../../reports/agent-noaa-replay.json).

## Оставшиеся ограничения

UTC+5, начало десятиминутного интервала и выпуск 23:00 по часам CSV —
явные исследовательские допущения, ещё не подтверждённые организаторами.
При другом ответе нужны согласование часовых целей с погодой и переобучение.
Погодная сетка и трёхчасовые опоры ограничивают пространственную и временную
детализацию. Прогноз нормализован; перевод в МВт требует номиналов турбин.
Контроллер агента работает по правилам (`policy`), LLM не вызывается.
