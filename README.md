# RentBox — прогноз выработки ВЭС

Проект команды RentBox для HackAlem AI: агент, который получает архивные
погодные прогнозы и рассчитывает почасовую выработку двух турбин на 24–48 часов.
Тестовый период кейса — февраль 2026 года.

**Текущий этап:** получены исходные данные, выполнена проверка их качества,
добавлено хранилище истории прогнозов на DuckDB. Модель, агент, API и интерфейс
находятся в разработке.

- [Журнал изменений и интерфейсы для совместной работы](CHANGELOG.md)
- [План работы и распределение задач](docs/PLAN.md)
- [Контракт API для фронта](docs/API.md)
- [Результаты проверки данных](reports/data-audit.md)
- [Скрипт проверки](scripts/audit_data.py)

Исходные CSV от организаторов находятся в `data/incoming/`.
Проверка данных запускается командой `python scripts/audit_data.py`
в окружении с pandas и numpy.

При разработке используются OpenAI Codex для анализа данных, подготовки
скриптов и проектной документации и Claude Code для хранилища истории прогнозов.
Источники датасетов указаны в отчёте проверки.
